# 성무슐랭 — 성무제 푸드코트 맛 대결 투표 시스템

2026 성무제 푸드코트 수상팀(🥇 교장상 · 🥈 생도대장상 · 🥉 생도전대장상)을 정하는 휴대폰 투표 시스템입니다.

```
휴대폰 (index.html) ──투표──▶ 구글폼 ──자동 저장──▶ 구글 시트
        ▲                                              │
        └──── 실시간 순위·운영본부 (Apps Script 웹 앱) ◀──┘
```

| 파일 | 역할 |
|---|---|
| `index.html` | 투표, 실시간 순위, 운영본부 화면. GitHub Pages로 배포됩니다. |
| `google-script.gs` | 구글 시트의 Apps Script에 붙여넣는 코드. 구글폼 생성, 집계, 실시간 순위, 운영본부 기능을 담당합니다. |
| `CLAUDE.md` | 다른 컴퓨터에서 Claude Code로 이어서 작업할 때 읽는 프로젝트 메모 |

| 주소 | 용도 |
|---|---|
| https://leeejunseo.github.io/foodcourt-vote/ | 투표 (QR용) |
| `…/?rank` | 실시간 순위 탭으로 바로 열기 |
| `…/?board` | 대형 화면 모드: 공개 단계에 맞춰 TOP 7 또는 시상대·전체 순위를 크게, 자동 갱신 |
| `…/?staff=<운영본부 코드>` | 운영본부 로그인 (PIN 필요) |
| `…/?staff=off` | 이 폰의 운영본부 모드 해제 |
| `…/?reset` | 이 폰에 저장된 내 투표 기록 지우기 (테스트용) |

## 1. 처음 설치 (새 구글 시트 기준)

1. 새 구글 시트 → **확장 프로그램 → Apps Script** → 원래 코드를 지우고 `google-script.gs` 전체를 붙여넣고 저장합니다.
2. 함수 목록에서 **`createForm`** → ▶ 실행합니다. 권한 경고가 뜨면 **고급 → (프로젝트)로 이동 → 허용**을 누릅니다. 본인이 만든 스크립트라서 뜨는 정상 경고입니다.
3. `설정` 탭 B3 칸의 **웹페이지 연결 링크**를 `index.html`의 `formPrefillLink`에 넣습니다.
4. **배포 → 새 배포 → ⚙ 웹 앱**을 고르고 실행 계정 **나**, 액세스 **모든 사용자**로 배포합니다. 나온 URL을 `index.html`의 `liveUrl`에 넣습니다.
5. 시트를 새로고침하고 메뉴 **🏆 투표 집계 → 운영본부 코드·PIN 설정**에서 코드와 PIN을 정합니다.
6. 구글폼 편집 화면에 '게시' 버튼이 보이면 누릅니다.

### 코드를 고친 뒤 다시 배포할 때

- `google-script.gs`를 다시 붙여넣고 저장한 뒤 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 누릅니다. 웹 앱 주소가 그대로 유지됩니다.
- **새 배포**를 하면 주소가 바뀝니다. 그때는 `index.html`의 `liveUrl`도 바꿔야 합니다.
- 운영본부 코드와 PIN은 스크립트 속성에 저장되어 있어서, 코드를 다시 붙여넣어도 그대로 유지됩니다.

## 2. 웹페이지 설정 (`index.html` 위쪽 `CONFIG`)

| 항목 | 내용 |
|---|---|
| `formPrefillLink` / `liveUrl` | 구글폼 연결 링크, 웹 앱 주소 |
| `booths` | 부스 20개. 순서가 곧 부스 번호이고, `name`이 시트에 기록되어 집계에 쓰입니다. |
| `classes` / `companies` | 기수(75~78기), 중대(1~8중대) |
| `voterTypes` | 생도 / 장병 / 외부인. 생도는 기수·중대·이름, 나머지는 이름·휴대폰 뒷 4자리를 입력합니다. |
| `liveRefreshSec` | 실시간 순위 갱신 간격(초) |
| `voteStart` / `voteEnd` | 화면에서만 막는 투표 시간 (비워두면 항상 열림). 실제 마감은 운영본부 탭에서 합니다. |

`main` 브랜치에 올리면 1~2분 뒤 사이트에 반영됩니다.

## 3. 운영

### 운영본부 탭 (운영본부 모드인 폰에만 보임, 버튼은 두 번 눌러야 적용)

| 버튼 | 하는 일 |
|---|---|
| 공개 화면 순위: **숨김** | "지금까지 ○○명이 투표했어요"만 보입니다. |
| 공개 화면 순위: **TOP 7** (처음 설정) | 상위 7개 부스를 **부스 번호순으로, 득표수 없이** 보여줍니다. 7위가 동점이면 모두 보여줍니다(예: 8곳). |
| 공개 화면 순위: **전체 순위** | 시상대와 전체 순위, 득표수를 보여줍니다. 시상식용입니다. |
| 투표 마감하기 / 다시 열기 | 마감하면 투표 화면이 닫히고, **마감 중에 들어온 표는 집계에서 빠집니다.** 마감하면 순위도 자동으로 숨김이 됩니다. |
| 전체 순위 (목록) | 공개 단계와 상관없이 운영본부에서는 득표수와 단독 지지 수가 보입니다. |

숨김·TOP 7일 때는 서버가 득표수를 아예 내보내지 않아서, 웹 앱 주소를 직접 열어도 순위를 알 수 없습니다.

시트 메뉴 **🏆 투표 집계**로도 같은 일을 할 수 있고, **집계 실행**을 누르면 `집계` 탭에 최종 순위와 수상이 정리됩니다.

> ⚠️ 구글폼 자체의 '응답 받기' 설정은 실제로 응답을 막지 못하는 경우가 있어, 마감은 반드시 **운영본부 탭이나 시트 메뉴**로 하세요.

### 집계 규칙

- 같은 사람(생도: 기수+중대+이름, 장병·외부인: 구분+뒷번호+이름)이 여러 번 투표하면 **마지막 투표만** 인정합니다.
- 같은 폰에서 온 표도 **마지막 1표만** 인정합니다. PIN으로 인증된 운영본부 폰은 예외입니다.
- 한 사람이 같은 부스를 두 번 고르면 1표로 칩니다.
- **동점:** 득표수가 같으면 **단독 지지**(해당 부스 한 곳만 선택한 표)가 많은 부스를 상위로 결정합니다. 단독 지지까지 같으면 같은 순위가 되고, 시트에 `(동점 — 운영본부 결정 필요)`로 표시됩니다.
- 무효가 된 표는 `이전투표`(바뀐 표)와 `마감후응답`(마감 중 표) 탭에 따로 기록됩니다.

## 4. 보안

- 운영본부 **코드와 PIN은 Apps Script 스크립트 속성에만** 있습니다. 이 저장소와 웹페이지에는 없습니다. 공개 저장소이니 **절대 파일에 적지 마세요.**
- 유출이 의심되면 시트 메뉴 **운영본부 코드·PIN 설정**에서 바꾸세요. 재배포 없이 바로 적용되고, 기존에 로그인한 폰은 모두 로그아웃됩니다. 그전에 운영본부 폰으로 받은 표는 그대로 인정됩니다.
- PIN을 5번 틀리면 10분간 잠깁니다. 링크 코드가 틀린 시도는 잠금에 반영하지 않습니다.
- 구글 시트 공유는 반드시 **제한됨**으로 둡니다. 웹 앱은 본인 계정 권한으로 돌아가서 공유하지 않아도 동작합니다.
- 브라우저를 바꾸거나 시크릿 창을 쓰면 기기 제한을 피할 수 있습니다. 웹페이지만으로는 완전히 막을 수 없어서, 공지에 부정 투표 경고를 넣고 필요하면 사후 점검합니다.

## 5. 테스트할 때 주의

- 실제 투표로 테스트했다면 **시트에서 그 줄을 꼭 지우세요.**
- 같은 폰에서 처음 화면을 다시 보려면 `?reset`을 붙여 엽니다. 기기 번호는 유지됩니다.

## 6. 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| 편집기에서 실행했는데 계속 로딩 중 | 시트 탭에 확인 창이 떠 있을 수 있습니다. 시트 탭에서 [확인]을 누르세요. |
| "운영본부 기능이 아직 서버에 없어요" / TOP 7을 눌렀더니 "이 기능이 아직 서버에 없어요" | Apps Script가 새 버전으로 배포되지 않았습니다. 배포 관리 → 새 버전으로 배포하세요. |
| "운영본부 코드·PIN이 아직 설정되지 않았어요" | 시트 메뉴에서 운영본부 코드·PIN을 설정하세요. |
| 실시간 순위가 "불러오는 중"에서 오래 걸림 | 한동안 호출이 없던 Apps Script는 첫 응답에 10초 가까이 걸릴 수 있습니다. |
| "Google hasn't verified this app" 경고 | 본인 스크립트라 정상입니다. Advanced → Go to … (unsafe) → Allow |
